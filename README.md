# Crowd Monitoring and Safety System

## Overview

The Crowd Monitoring and Safety System is an IoT and Computer Vision based solution designed to monitor crowd density and environmental conditions in real time.

The system uses an ESP32-CAM module with OpenCV and YOLO for crowd detection and a DHT11 sensor for temperature and humidity monitoring. When unsafe crowd conditions are detected, the system automatically sends alert notifications through Email and SMS services.

## Features

* Real-time crowd detection
* Crowd density estimation
* Temperature and humidity monitoring
* Email alert system
* SMS alert system using Twilio API
* Low-cost IoT implementation
* Real-time monitoring and safety management

## Working Principle

1. ESP32-CAM captures live video.
2. YOLO detects and counts people.
3. DHT11 monitors temperature and humidity.
4. Data is analyzed in real time.
5. Email and SMS alerts are generated when safety thresholds are exceeded.
